# PythonLife GitHub Profile README Templates

Four clean profile templates for Python developers, plus an optional script that keeps a "latest posts" section up to date.

## Templates

| Template | Best for |
|---|---|
| [Clean Classic](templates/01-clean-classic.md) | A simple, fast-loading profile |
| [about_me.py](templates/02-about-me-py.md) | A profile written as Python code |
| [Learning in Public](templates/03-learning-in-public.md) | Tracking a 30-day learning journey |
| [Project Showcase](templates/04-project-showcase.md) | Developers with several finished projects |

## Quick start

1. Create a public repository named exactly like your GitHub username, with a `README.md`.
2. Copy a template into it and replace every `{{PLACEHOLDER}}`.
3. Commit.

Placeholders, automation setup and a pre-publish checklist are in the [guide](docs/GUIDE.md).
