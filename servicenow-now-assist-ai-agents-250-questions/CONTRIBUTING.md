# Contributing

Corrections and new questions are welcome.

## Adding or fixing a question

1. Edit the topic file in `questions/` and keep the same layout: heading, level, collapsible answer.
2. Keep answers short, factual and in plain language.
3. Include a source link in your pull request for any product fact. Mark release-specific facts in the answer (for example, "In the Australia release...").
4. Update `data/questions.json` and `data/questions.csv` so they match the markdown.
5. Do not copy text from ServiceNow documentation. Write answers in your own words.

## Levels

- **Beginner:** definitions and names.
- **Intermediate:** how things work and why.
- **Advanced:** design decisions, trade-offs and scenarios.

## Reporting outdated answers

Open an issue with the question ID, what changed, and a link to the documentation.
