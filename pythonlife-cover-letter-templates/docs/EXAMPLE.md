# Worked example

A filled-in version of the [Junior Python Developer](../templates/01-junior-python-developer.md) template. All names are fictional.

```text
Jane Doe
jane@example.com · +1 555 0100 · github.com/janedoe

13 November 2026

Dear Ms. Alvarez,

I noticed that Brightline Software recently launched a public API for its invoicing product. That is the kind of problem I want to work on, which is why I am applying for the Junior Python Developer role.

Over the past 8 months I built Invoicely, a command-line tool that turns CSV files into PDF invoices. It is tested with pytest at 92% coverage, documented, and used by 14 freelancers in my local community. I also contributed a bug fix to an open-source date library, which taught me how to read an unfamiliar codebase and write a reviewable pull request.

Your posting asks for REST API experience and automated testing. I used FastAPI and pytest for both in Invoicely, and the code is public at github.com/janedoe so you can judge it directly.

I would welcome a conversation about how I can contribute to the API team. Thank you for your time.

Sincerely,
Jane Doe
```

## Why it works

- **Specific opening:** it names something the company actually did.
- **Measurable proof:** 8 months, 92% coverage, 14 users.
- **Mapped to the posting:** each requirement is matched to evidence.
- **Verifiable:** a link lets the reader check the claims.
- **Short:** about 170 words, well under one page.
