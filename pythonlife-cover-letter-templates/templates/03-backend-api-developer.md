# Backend and API Developer

**Use when:** You have professional or substantial project experience and want to lead with measurable engineering results.
**Length:** About 240 words

## Letter

```text
{{YOUR_NAME}}
{{EMAIL}} · {{PHONE}} · github.com/{{GITHUB}}

{{DATE}}

Dear {{HIRING_MANAGER}},

I am applying for the {{ROLE}} position at {{COMPANY}}. Your team is {{SPECIFIC_THING}}, and I have spent the last {{YEARS}} years building Python services with the same demands: reliability, clear interfaces and fast iteration.

Recent results:

- At {{CURRENT_EMPLOYER}} I {{ACHIEVEMENT_1}}, improving {{METRIC_1}} by {{PERCENT_1}}.
- I designed {{API_OR_SERVICE}} using {{TECH_USED}}, now handling {{SCALE}}.
- I introduced {{PRACTICE}} (for example testing, CI or monitoring), which {{OUTCOME}}.

You ask for experience with {{REQUIREMENT_1}} and {{REQUIREMENT_2}}. Both are part of my daily work, and I can walk you through the design decisions behind them.

I would value a conversation about the technical challenges on {{TEAM_OR_PRODUCT}} and where I could contribute in the first six months.

Sincerely,
{{YOUR_NAME}}
```

## Tailoring notes

- Every bullet needs a verb, a thing, and a number. Replace vague claims with measurable ones.
- Mention scale only if it is true and relevant: requests per second, data volume, uptime.
- Offer to explain a design decision. It signals confidence and invites a technical conversation.
