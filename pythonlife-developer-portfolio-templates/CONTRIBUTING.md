# Contributing

Thank you for helping improve these templates.

## Principles

- Each template stays a single `index.html` with no build step and no dependencies.
- No JavaScript unless it is essential and documented.
- Every template must work in light and dark mode, on mobile, and when printed.
- Keep placeholders in the form `{{LIKE_THIS}}` and document each one in `docs/GUIDE.md`.

## Submitting a change

1. Fork the repository and create a branch.
2. Make your change and open the file in a browser at mobile and desktop widths.
3. Check keyboard navigation and contrast in both color schemes.
4. Update `docs/GUIDE.md` and `CHANGELOG.md` where relevant.
5. Open a pull request describing what changed and why.

## Reporting issues

Use the bug report template and include the template name, browser, and a screenshot.
