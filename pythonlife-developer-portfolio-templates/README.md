# PythonLife Developer Portfolio Templates

![License: MIT](https://img.shields.io/badge/license-MIT-3776ab) ![Dependencies: none](https://img.shields.io/badge/dependencies-none-ffd43b) ![Version](https://img.shields.io/badge/version-1.1.0-3776ab)

Seven professional, single-file portfolio websites for Python developers. No build step, no JavaScript, no dependencies. Edit one file and publish for free on GitHub Pages.

## Templates

| Template | Best for |
|---|---|
| [Classic](templates/classic/index.html) | A clean, general-purpose portfolio with project cards |
| [Terminal](templates/terminal/index.html) | A Python REPL style page with personality |
| [Case Study](templates/case-study/index.html) | Showing how you work: problem, approach, result |
| [Notebook](templates/notebook/index.html) | Data scientists and analysts, Jupyter style |
| [API Reference](templates/api-reference/index.html) | Backend and API developers, styled as API docs |
| [Freelancer](templates/freelancer/index.html) | Selling services with a clear call to action |
| [Journey](templates/journey/index.html) | Juniors and career switchers, timeline format |

## Features

- Light and dark mode that follows the visitor's system setting
- Responsive layout for phones, tablets and desktops
- Accessible: skip link, semantic landmarks, keyboard focus styles
- SEO ready: title, description, Open Graph tags, theme color and favicon
- Print friendly, so the page can double as a one-page CV
- Brand colors controlled by two CSS variables

## Quick start

1. Copy the template folder you want.
2. Open `index.html` and replace every `{{PLACEHOLDER}}`. Search for `{{` to find them.
3. Open the file in a browser to preview it.
4. Publish with GitHub Pages. See the [guide](docs/GUIDE.md).
