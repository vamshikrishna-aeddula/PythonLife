# PythonLife Developer Portfolio Templates

Three single-file portfolio websites for Python developers. No build step, no dependencies, no JavaScript. They work in light and dark mode, on phones and desktops, and deploy free on GitHub Pages.

## Templates

| Template | Best for |
|---|---|
| [Classic](templates/classic/index.html) | A clean general-purpose portfolio with project cards |
| [Terminal](templates/terminal/index.html) | A Python REPL style page with personality |
| [Case Study](templates/case-study/index.html) | Showing how you think: problem, approach, result |

## Quick start

1. Choose a template folder and open its `index.html`.
2. Replace every `{{PLACEHOLDER}}`. Search for `{{` to find them.
3. Open the file in a browser to preview it.
4. Publish with GitHub Pages. Steps are in the [guide](docs/GUIDE.md).
