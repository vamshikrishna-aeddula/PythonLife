# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-13

### Added
- Notebook, API Reference, Freelancer and Journey templates.
- Template chooser and new placeholders in the guide.

## [1.0.0] - 2026-11-13

### Added
- Classic, Terminal and Case Study portfolio templates.
- Light and dark mode, responsive layout, print styles.
- Accessibility basics: skip link, semantic landmarks, visible focus states.
- SEO basics: title, description, Open Graph tags, theme color, favicon.
- Guide covering customization, publishing, SEO and accessibility.
